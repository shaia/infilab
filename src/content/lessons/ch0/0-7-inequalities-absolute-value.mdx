<Hook title="כמה רחוק מ-3?">

על מספר $x$ יודעים רק דבר אחד: המרחק שלו מ-1 קטן מ-1. כמה רחוק $x$ יכול להיות מ-3?

נסו לענות לפני שממשיכים. האם המרחק מ-3 יכול להיות $2.9$? האם הוא יכול להיות $3$? ו-$0.5$?

ושאלה שנייה, משחק הערכה: מצאו ביטוי פשוט שגדול או שווה ל-$\frac{1}{n^2+3n}$ לכל $n$ טבעי, וביטוי פשוט שקטן ממנו או שווה לו. המספרים $1$ ו-$0$ עונים על זה, אבל לא אומרים כלום על הביטוי. אנחנו רוצים חסמים **מאותו סדר גודל**: ביטויים שגם הם קטנים בערך פי 100 כש-$n$ גדל פי 10.

נחזור לשתי השאלות בהמשך השיעור, ונענה על הראשונה בשתי שורות, בלי לבדוק אף $x$. הכלים הם ערך מוחלט ואי-שוויון המשולש, ושניהם ילוו אתכם בכל הקורס: כמעט כל הוכחה באינפי 1 היא שרשרת של אי-שוויונות כאלה.

</Hook>

<Step fig="fig-0-7a" set={{ mode: 'band', a: 1, r: 1, rel: '<', x: 0.5 }}>

$|x|$ הוא המרחק של $x$ מאפס, ו-$|x-a|$ הוא המרחק בין $x$ ל-$a$. למשל $|5-2| = |2-5| = 3$.
באיור הקבוצה של כל ה-$x$ שמקיימים $|x-1|<1$: כל המספרים שמרחקם מ-1 קטן מ-1. זו בדיוק הקבוצה משאלת הפתיחה, הקטע מ-0 עד 2.
הקצוות 0 ו-2 חלולים: המרחק שלהם מ-1 הוא בדיוק 1, ו-1 אינו קטן מ-1. גררו את נקודת הבדיקה $x$ (או השתמשו במחוון שמתחת לאיור) וראו מתי היא מלאה ומתי חלולה.

</Step>

<Step fig="fig-0-7a" set={{ mode: 'band', a: 1, r: 2, rel: '<=', x: 3 }}>

**כתיב.** קבוצת כל המספרים מ-$p$ עד $q$ נכתבת בסוגריים: סוגר מרובע אם הקצה שייך, ועגול אם לא. $(0,2)$ הוא הקטע מ-0 עד 2 בלי הקצוות, ו-$[-1,3]$ הוא הקטע מ-$-1$ עד 3 עם הקצוות. $(3,\infty)$ הוא כל המספרים הגדולים מ-3, ו-$\cup$ הוא <Term id="set-union">איחוד</Term>, משיעור 0.6.

עכשיו המרכז 1, הרדיוס 2, והסימן $\le$: הקבוצה היא $[-1,3]$, והקצוות **מלאים**, כי מרחקם מ-1 הוא בדיוק 2. החליפו לסימן $>$ (בכפתורים): המספרים **רחוקים** מ-1 יותר מ-2 הם שתי קרניים, $(-\infty,-1)\cup(3,\infty)$, כי $x$ רחוק משמאל **או** רחוק מימין. "קרוב" נותן קטע אחד, ו"רחוק" נותן איחוד של שני חלקים.

</Step>

<Step fig="fig-0-7a" set={{ mode: 'band', a: 0, r: 1, rel: '<', x: 3 }}>

**משימה.** הזיזו את המרכז $a$ ואת הרדיוס $r$ (את המעוין ואת הריבוע הקטן באיור, או את המחוונים) כך שהקבוצה תהיה בדיוק הקטע הפתוח $(-1,5)$.
איזה מרכז מתאים? איזה רדיוס? ומה צריך להיות הסימן?

</Step>

<Step fig="fig-0-7a" set={{ mode: 'triangle', x: 3, y: -2 }}>

בתצוגת אי-שוויון המשולש: $x = 3$, ומהקצה שלו $y = -2$ חוזר שמאלה, אל $x+y = 1$. מתחת לישר, הפס העליון הוא הדרך שעשו שני החצים, $|x|+|y| = 5$, והתחתון הוא המרחק מאפס בסוף, $|x+y| = 1$. ההליכה חזרה "בזבזה" דרך.
**משימה.** הזיזו את $x$ או את $y$, שניהם שונים מאפס, עד ששני הפסים שווים. מתי זה קורה? השוו לחיזוי שלכם.

</Step>

<Step fig="fig-0-7a" set={{ mode: 'two', a: 2, b: -1, c: 5, twoRel: '<', x: 4 }}>

בתצוגה השלישית יש שתי נקודות, $a = 2$ ו-$b = -1$, והקבוצה היא כל ה-$x$ שסכום המרחקים שלהם משתי הנקודות קטן מ-5: הקטע $(-2,3)$.
הזיזו את $x$ בין $a$ ל-$b$: סכום המרחקים לא משתנה, והוא תמיד 3, המרחק בין הנקודות.
**משימה.** הגדילו את $c$ מאפס, ועצרו ב-$c$ הגדול ביותר שבשבילו הקבוצה עדיין ריקה. למה דווקא שם?

</Step>

<Explain title="ערך מוחלט ומרחק" id="abs-distance">

<Step fig="fig-0-7b" set={{ mode: 'band', a: 0, r: 3, rel: '<', x: 2 }}>

<Term id="absolute-value">הערך המוחלט</Term> של מספר ממשי $x$ מוגדר לפי הסימן שלו:

<Formula tex="|x| = \begin{cases} x, & x \ge 0 \\ -x, & x < 0 \end{cases}" label="ערך מוחלט" />

למשל $|4| = 4$, $|-4| = 4$, $|0| = 0$. על ישר המספרים $|x|$ הוא המרחק של $x$ מאפס, ו-$|x-a|$ הוא המרחק בין $x$ ל-$a$. (בשיעור 1.2 נלמד את אקסיומות הסדר, הכללים הבסיסיים של היחס $<$, ונוכיח מהן את תכונות הערך המוחלט. כאן משתמשים במה שמכירים מבית הספר.)

</Step>

כל אחת מהתכונות הבאות נבדקת לפי מקרים: $x \ge 0$ ו-$x < 0$, ובתכונה של המכפלה $|xy|$ ארבעה מקרים, לפי הסימנים של $x$ ושל $y$:

- $|x| \ge 0$, ו-$|x| = 0$ רק כש-$x = 0$.
- $|-x| = |x|$, ולכן $|x-a| = |a-x|$: המרחק מ-$x$ ל-$a$ שווה למרחק מ-$a$ ל-$x$.
- $-|x| \le x \le |x|$. (כש-$x \ge 0$: $x = |x|$ ו-$-|x| \le 0 \le x$. כש-$x<0$: $x = -|x|$ ו-$x < 0 < |x|$.)
- $|x|^2 = x^2$, ו-$|xy| = |x|\cdot|y|$.

<Note kind="warn">
אין כלל כזה לסכום: $|1 + (-1)| = 0$, אבל $|1| + |-1| = 2$. הערך המוחלט אינו "מוחק את המינוסים" בתוך סכום. מה שכן נכון על סכום הוא אי-שוויון, ונוכיח אותו בהמשך השיעור.
</Note>

</Explain>

<Explain title="אי-שוויונות עם ערך מוחלט" id="solving">

<Step fig="fig-0-7b" set={{ mode: 'band', a: 0, r: 3, rel: '<', x: -2 }}>

עוד על הכתיב. <Term id="real-interval">קטע</Term> הוא קבוצת כל המספרים בין שני קצוות: $(p,q)$ הוא הקטע **הפתוח**, בלי הקצוות, $[p,q]$ הקטע **הסגור**, עם הקצוות, ו-$[p,q)$ חצי-פתוח. גם $(-\infty, q]$ ו-$(p,\infty)$ הם קטעים (הסימן $\infty$ אינו מספר, ולכן בצד שלו הסוגריים תמיד עגולים).

**הכלל המרכזי.** יהי $r > 0$. לכל $t$ ממשי:

<Formula tex="|t| < r \iff -r < t < r" label="ערך מוחלט קטן מ-r" />

**רעיון ההוכחה:** מפצלים לפי הסימן של $t$, ובכל מקרה מחליפים את $|t|$ ב-$t$ או ב-$-t$.

**הוכחה.** נניח $|t| < r$. אם $t \ge 0$, אז $t = |t| < r$, וגם $t \ge 0 > -r$. אם $t < 0$, אז $-t = |t| < r$, כלומר $t > -r$, וגם $t < 0 < r$. בשני המקרים $-r < t < r$.
בכיוון השני, נניח $-r < t < r$. אם $t \ge 0$, אז $|t| = t < r$. אם $t < 0$, אז $|t| = -t$, ומ-$-r < t$ נובע $-t < r$. בשני המקרים $|t| < r$.

</Step>

אותה הוכחה, עם $\le$ במקום $<$, נותנת $|t| \le r \iff -r \le t \le r$ (וזה נכון גם כש-$r = 0$).

ומה עם "גדול מ"? $|t| > r$ היא השלילה של $|t| \le r$, כלומר של "$-r \le t$ **וגם** $t \le r$". לפי <Term id="de-morgan-logic">כללי דה-מורגן</Term> משיעור 0.2, השלילה של "וגם" היא "או" של השלילות: $t < -r$ **או** $t > r$. בסימנים, עם $\lor$ ל"או":

<Formula tex="|t| > r \iff (t > r) \lor (t < -r)" label="ערך מוחלט גדול מ-r" />

הפתרון הוא איחוד של שני חלקים, לא קטע אחד.

<Step fig="fig-0-7b" set={{ mode: 'band', a: 2, r: 3, rel: '<', x: 4 }}>

<div id="centre-radius" />

**$|x-a| < r$ הוא קטע פתוח.** מציבים $t = x - a$ בכלל: $|x-a| < r$ שקול ל-$-r < x-a < r$, כלומר ל-$a - r < x < a + r$.

<Formula tex="|x-a| < r \iff a-r < x < a+r" label="הקטע שמרכזו a ורדיוסו r" />

כלומר קבוצת ה-$x$ עם $|x-a|<r$ היא <Term id="interval-centre-radius">הקטע הפתוח שמרכזו $a$ ורדיוסו $r$</Term>: $(a-r,\ a+r)$. ולהפך: לקטע פתוח $(p,q)$ המרכז הוא האמצע $\frac{p+q}{2}$, והרדיוס הוא חצי האורך $\frac{q-p}{2}$. באיור: $(-1,5)$ הוא $|x-2|<3$.

**את המשפט הזה תפגשו שוב בפרק 2, באותיות אחרות:** $|x-L|<\varepsilon$ הוא הקטע הפתוח שמרכזו $L$ ורדיוסו $\varepsilon$, כלומר $L-\varepsilon < x < L+\varepsilon$. ($\varepsilon$, אפסילון, היא רק אות יוונית למספר חיובי.) הגדרת הגבול כולה בנויה על הקטע הזה.

</Step>

<Step fig="fig-0-7b" set={{ mode: 'band', a: 1.5, r: 2.5, rel: '<=', x: 0 }}>

**מתכון 1: ערך מוחלט אחד.** פותחים לפי הכלל ופותרים את שני אי-השוויונות.
$|2x-3| \le 5$ שקול ל-$-5 \le 2x - 3 \le 5$. מוסיפים 3: $-2 \le 2x \le 8$. מחלקים ב-2, שהוא חיובי ולכן הסימנים לא מתהפכים: $-1 \le x \le 4$. הפתרון הוא $[-1, 4]$.
בדיקה באיור: לפי $|xy| = |x|\cdot|y|$, $|2x-3| = \left|2\left(x - \frac32\right)\right| = 2\left|x - \frac32\right|$, ולכן אי-השוויון הוא $\left|x-\frac32\right| \le \frac52$: מרכז $1.5$, רדיוס $2.5$, קצוות מלאים.

</Step>

<Step fig="fig-0-7b" set={{ mode: 'band', a: -1, r: 2, rel: '>', x: 2 }}>

**מתכון 2: "גדול מ".** $|x+1| > 2$ שקול ל-$x + 1 > 2$ **או** $x + 1 < -2$, כלומר $x > 1$ או $x < -3$. הפתרון: $(-\infty,-3) \cup (1,\infty)$.
שימו לב ש-$|x+1| = |x-(-1)|$ הוא המרחק מ-$-1$, לא מ-1: הקבוצה היא המספרים שרחוקים מ-$-1$ יותר מ-2.

</Step>

<Note kind="warn">
שתי טעויות נפוצות. (1) "מורידים" את הערך המוחלט ופותרים רק $x+1>2$: מאבדים חצי מהפתרונות, למשל $x=-10$. (2) כותבים את "או" כשרשרת אחת, $-3 > x > 1$: אין אף $x$ כזה. שרשרת $p < x < q$ פירושה "וגם", ומתאימה רק ל"קטן מ".
</Note>

<Step fig="fig-0-7b" set={{ mode: 'two', a: 2, b: -1, c: 5, twoRel: '<', x: 0 }}>

<div id="cases" />

**מתכון 3: כמה ערכים מוחלטים.** מפצלים את הישר בנקודות שבהן כל ביטוי בתוך ערך מוחלט מחליף סימן, ובכל חלק כותבים את הביטוי בלי ערך מוחלט. נקודת פיצול אפשר לשייך לכל אחד משני החלקים שלידה (בה הביטוי שווה לאפס, ושתי הכתיבות נכונות); העיקר שכל $x$ נבדק בדיוק בחלק אחד.
נפתור $|x-2| + |x+1| < 5$. הביטויים מחליפים סימן ב-$x = 2$ וב-$x = -1$:

- $x \ge 2$: שני הביטויים אי-שליליים, והסכום הוא $(x-2) + (x+1) = 2x-1$. התנאי $2x - 1 < 5$ נותן $x < 3$. בחלק הזה: $[2, 3)$.
- $-1 \le x < 2$: הסכום הוא $(2-x) + (x+1) = 3$, ו-$3 < 5$ תמיד. כל החלק פותר: $[-1, 2)$.
- $x < -1$: הסכום הוא $(2-x) + (-x-1) = 1-2x$. התנאי $1 - 2x < 5$ נותן $x > -2$. בחלק הזה: $(-2, -1)$.

הפתרון הוא האיחוד: $(-2,-1) \cup [-1,2) \cup [2,3) = (-2, 3)$. באיור: הסכום הוא סכום המרחקים מ-2 ומ-$-1$. בין שתי הנקודות הוא קבוע, 3, ומחוץ להן הוא גדל.

</Step>

**מתכון 4: העלאה בריבוע.** אם שני האגפים אי-שליליים, מותר להעלות בריבוע: לכל $p, q \ge 0$, $p < q \iff p^2 < q^2$.

- **כיוון ראשון.** נניח $0 \le p < q$. כופלים את $p < q$ ב-$p \ge 0$: $p^2 \le pq$ (ב-$\le$, כי כש-$p = 0$ שני האגפים אפס). כופלים את $p < q$ ב-$q$, שהוא חיובי (כי $q > p \ge 0$): $pq < q^2$. ביחד $p^2 < q^2$.
- **כיוון שני, בקונטרפוזיטיב** (משיעור 0.2). נניח שלא $p < q$, כלומר $p \ge q \ge 0$. אותו חישוב עם $\le$ נותן $q^2 \le qp \le p^2$, כלומר לא $p^2 < q^2$.
- **ומשני הכיוונים:** $p = q \iff p^2 = q^2$. אם $p \ne q$, אחד מהם קטן מהשני, ולפי הכיוון הראשון גם הריבועים שונים.

מכיוון ש-$|u|^2 = u^2$:

<Formula tex="|u| < |v| \iff u^2 < v^2" label="השוואת ערכים מוחלטים" />

למשל $|x-1| < |x+1|$ שקול ל-$(x-1)^2 < (x+1)^2$, כלומר ל-$-2x < 2x$, כלומר ל-$x > 0$: המספרים שקרובים ל-1 יותר מאשר ל-$-1$ הם בדיוק החיוביים. בלי הערכים המוחלטים זה לא עובד: $-3 < 2$, אבל $9 > 4$.

</Explain>

<Explain title="אי-שוויון המשולש" id="triangle">

<Step fig="fig-0-7b" set={{ mode: 'triangle', x: 3, y: -2 }}>

**משפט (<Term id="triangle-inequality">אי-שוויון המשולש</Term>).** לכל $a, b$ ממשיים:

<Formula tex="|a+b| \le |a| + |b|" label="אי-שוויון המשולש" />

ויש שוויון בדיוק כש-$ab \ge 0$, כלומר כש-$a$ ו-$b$ אינם בסימנים מנוגדים.

**רעיון ההוכחה:** כל מספר נמצא בין מינוס הערך המוחלט שלו לבין הערך המוחלט שלו. מחברים את שני "הסנדוויצ'ים", וחוזרים לערך מוחלט בעזרת הכלל של הקטע.

**הוכחה.**
1. לכל $t$ ממשי $-|t| \le t \le |t|$ (ראינו בשני מקרים). לכן $-|a| \le a \le |a|$ ו-$-|b| \le b \le |b|$.
2. מחברים את שני אי-השוויונות: $-(|a|+|b|) \le a + b \le |a| + |b|$.
3. לפי הכלל $|t| \le r \iff -r \le t \le r$, עם $t = a+b$ ו-$r = |a|+|b| \ge 0$, מקבלים $|a+b| \le |a| + |b|$.

</Step>

<Step fig="fig-0-7b" set={{ mode: 'triangle', x: 3, y: 2 }}>

<div id="equality" />

**מתי יש שוויון?** שני האגפים אי-שליליים, ולכן הם שווים בדיוק כשהריבועים שלהם שווים (מתכון 4: $p = q \iff p^2 = q^2$ עבור $p, q \ge 0$):

$$
|a+b|^2 = a^2 + 2ab + b^2, \qquad \big(|a|+|b|\big)^2 = a^2 + 2|ab| + b^2 .
$$

הריבועים שווים בדיוק כש-$ab = |ab|$, כלומר כש-$ab \ge 0$. (החישוב הזה הוא גם הוכחה שנייה לאי-השוויון עצמו: $ab \le |ab|$ תמיד.)

**בחזרה לשאלת החיזוי.** $|x+y| = |x|+|y|$ בדיוק כש-$xy \ge 0$: כש-$x$ ו-$y$ באותו סימן, או שאחד מהם אפס. לא תמיד, לא רק כש-$x = y$, ולא רק כשאחד מהם אפס. באיור: כשהחץ $y$ ממשיך באותו כיוון של $x$, לא "מבזבזים" דרך.

</Step>

**השם.** מציבים $a = x - y$ ו-$b = y - z$, ואז $a + b = x - z$:

<Formula tex="|x-z| \le |x-y| + |y-z|" label="אי-שוויון המשולש, צורת המרחק" />

המרחק מ-$x$ ל-$z$ אינו גדול מסכום המרחקים כשעוצרים בדרך בנקודה $y$. (במישור: צלע במשולש אינה ארוכה מסכום שתי האחרות, ומכאן השם.) ומפעילים את המשפט פעמיים: $|a+b+c| \le |a|+|b|+|c|$.

<Step fig="fig-0-7b" set={{ mode: 'triangle', x: 3, y: -2 }}>

<div id="reverse" />

**משפט (הצורה ההפוכה).** לכל $a, b$ ממשיים:

<Formula tex="\big||a|-|b|\big| \le |a-b|" label="אי-שוויון המשולש ההפוך" />

**רעיון ההוכחה:** כותבים את $a$ כסכום, $a = (a-b) + b$, ומפעילים עליו את אי-שוויון המשולש. זה נותן חסם על $|a|-|b|$; אותו טיעון עם $a$ ו-$b$ בתפקידים הפוכים נותן חסם על $|b|-|a|$.

**הוכחה.**
1. לפי אי-שוויון המשולש, $|a| = |(a-b) + b| \le |a-b| + |b|$, ולכן $|a| - |b| \le |a-b|$.
2. באותה דרך, $|b| = |(b-a) + a| \le |b-a| + |a|$, ולכן $|b| - |a| \le |b-a| = |a-b|$, כלומר $-|a-b| \le |a|-|b|$.
3. משני השלבים: $-|a-b| \le |a| - |b| \le |a-b|$, ולפי הכלל של הקטע, $\big||a|-|b|\big| \le |a-b|$.

</Step>

אי-שוויון המשולש חוסם **מלמעלה**: הוא אומר שביטוי לא גדול מדי. הצורה ההפוכה חוסמת **מלמטה**: $|a-b| \ge |a| - |b|$. שימושי במיוחד: $|a| = |x + (a-x)| \le |x| + |x-a|$, ולכן $|x| \ge |a| - |x-a|$. כלומר אם $a \ne 0$ ו-$|x-a| < \frac{|a|}{2}$, אז $|x| > \frac{|a|}{2}$: מספר קרוב ל-$a$ אינו קרוב מדי לאפס. (כש-$a = 0$ אין כאן כלום: מספר קרוב לאפס יכול להיות אפס.)

<Note kind="warn">
אל תהפכו את הכיוון: $|a-b| \le |a| - |b|$ **אינו** נכון. עבור $a = 0$, $b = 1$: אגף שמאל $1$ ואגף ימין $-1$. וגם $|a+b| \ge |a|+|b|$ אינו נכון: $|1+(-1)| = 0 < 2$.
</Note>

<Step fig="fig-0-7b" set={{ mode: 'band', a: 1, r: 1, rel: '<', x: 0.5 }}>

<div id="hook-answer" />

**התשובה לשאלת הפתיחה.** נתון $|x-1| < 1$, ורוצים לדעת מה אפשר לומר על $|x-3|$. הטכניקה היא <Term id="add-and-subtract">הוספה והחסרה</Term>: כותבים את $x - 3$ כסכום של מה שידוע, $x-1$, ושל מספר: $x - 3 = (x-1) + (1-3) = (x-1) - 2$.

- **מלמעלה**, לפי אי-שוויון המשולש: $|x-3| \le |x-1| + |-2| < 1 + 2 = 3$.
- **מלמטה**, לפי הצורה ההפוכה: $|x-3| = |(x-1) - 2| \ge |-2| - |x-1| > 2 - 1 = 1$.

כלומר $1 < |x-3| < 3$. ואי אפשר לשפר: $x$ ממלא את הקטע $(0,2)$, ובו $|x-3| = 3-x$ מקבל כל ערך בין 1 ל-3. המרחק $2.9$ מתקבל ב-$x = 0.1$; המרחקים 3 ו-$0.5$ לא מתקבלים.

</Step>

</Explain>

<Explain title="חסימה מלמעלה ומלמטה" id="estimates">

<Step fig="fig-0-7b" set={{ mode: 'means', a: 1, b: 4 }}>

לחסום ביטוי **מלמעלה** פירושו למצוא מספר, או ביטוי פשוט יותר, שהביטוי **לא גדול ממנו** בכל התחום. לחסום **מלמטה**: שהביטוי **לא קטן ממנו**. (בשיעור 1.4 נקרא למספרים כאלה חסם מלעיל וחסם מלרע של קבוצה.) הכלי הראשון:

**משפט (<Term id="am-gm-inequality">אי-שוויון הממוצעים</Term>).** לכל $a, b \ge 0$:

<Formula tex="\frac{a+b}{2} \ge \sqrt{ab}" label="אי-שוויון הממוצעים" />

ויש שוויון בדיוק כש-$a = b$. אגף שמאל הוא <Term id="arithmetic-mean">הממוצע החשבוני</Term>, ואגף ימין <Term id="geometric-mean">הממוצע ההנדסי</Term>. באיור: $a = 1$, $b = 4$, הממוצע החשבוני $2.5$, ההנדסי $2$.

**רעיון ההוכחה:** ריבוע של מספר ממשי אינו שלילי. לוקחים את הריבוע של $\sqrt a - \sqrt b$ ופותחים סוגריים.

**הוכחה.** כיוון ש-$a, b \ge 0$, השורשים $\sqrt a$, $\sqrt b$ מוגדרים, ו-$\sqrt a \cdot \sqrt b = \sqrt{ab}$. לכן

$$
0 \le \left(\sqrt a - \sqrt b\right)^2 = a - 2\sqrt{ab} + b ,
$$

כלומר $a + b \ge 2\sqrt{ab}$. מחלקים ב-2. שוויון יש בדיוק כש-$\left(\sqrt a - \sqrt b\right)^2 = 0$, כלומר כש-$\sqrt a = \sqrt b$, כלומר כש-$a = b$ (מעלים בריבוע; שני הצדדים אי-שליליים).

</Step>

<Step fig="fig-0-7b" set={{ mode: 'means', a: 3, b: 3 }}>

הזיזו באיור את $a$ ואת $b$: הממוצע ההנדסי לעולם לא עובר את החשבוני, והם נפגשים רק כש-$a = b$ (כאן $a = b = 3$).
**שימוש: חסם מלמטה שמושג** (יש $x$ שבו הביטוי שווה לו). לכל $x > 0$, עם $a = x$ ו-$b = \frac1x$: $\frac{x + \frac1x}{2} \ge \sqrt{x \cdot \frac1x} = 1$, כלומר $x + \frac1x \ge 2$. השוויון מתקבל כש-$x = \frac1x$, כלומר ב-$x = 1$, ולכן 2 הוא הערך הקטן ביותר של $x + \frac1x$ עבור $x>0$. הסוד: לבחור $a$ ו-$b$ שהמכפלה שלהם קבועה.

</Step>

<Note kind="warn">
אי-שוויון הממוצעים דורש $a, b \ge 0$, ולא רק $ab \ge 0$. עבור $a = b = -1$: $\frac{a+b}{2} = -1$, אבל $\sqrt{ab} = 1$. ההוכחה נשברת כבר בשורה הראשונה: $\sqrt{-1}$ אינו מספר ממשי. מה שנכון לכל $u, v$ ממשיים הוא $2uv \le u^2 + v^2$, מ-$(u-v)^2 \ge 0$.
</Note>

<div id="fractions">

**הכלי השני: הערכה של שבר.** לשבר עם מונה ומכנה חיוביים:

- **מלמעלה:** מגדילים את המונה או מקטינים את המכנה (ומשאירים אותו חיובי). כל אחת מהפעולות מגדילה את השבר.
- **מלמטה:** מקטינים את המונה או מגדילים את המכנה.

כל החלפה צריכה נימוק שמתקיים **לכל** $n$ בתחום. נחזור למשחק ההערכה: לחסום את $\frac{1}{n^2+3n}$, עבור $n$ טבעי. החסמים $\frac{1}{n^2+3n} \le \frac14$ ו-$\frac{1}{n^2+3n} \ge 0$ נכונים (הראשון כי המכנה לפחות 4), אבל הם לא קטנים כש-$n$ גדל, ולכן לא מספרים כמה הביטוי קטן. מחפשים חסמים מהצורה $\frac{C}{n^2}$:

- מלמעלה: $n^2 + 3n \ge n^2$, ולכן $\frac{1}{n^2+3n} \le \frac{1}{n^2}$. (הקטנו את המכנה.)
- מלמטה: לכל $n \ge 1$ מתקיים $n \le n^2$, ולכן $n^2 + 3n \le n^2 + 3n^2 = 4n^2$, ו-$\frac{1}{n^2+3n} \ge \frac{1}{4n^2}$. (הגדלנו את המכנה.)

ביחד: $\frac{1}{4n^2} \le \frac{1}{n^2+3n} \le \frac{1}{n^2}$. הטריק החוזר: מחליפים כל מחובר במכנה בכפולה של **החזקה הגבוהה ביותר** של $n$ שבו, כאן $n^2$, בעזרת $1 \le n \le n^2$ לכל $n \ge 1$. (החזקה הגבוהה היא זו שגדלה הכי מהר; עבור $n$ קטן היא לא בהכרח המחובר הגדול: ב-$n = 1$, $3n = 3 > 1 = n^2$. לכן מנמקים באי-שוויון שנכון לכל $n$, לא ב"זה זניח".) בדיקה עם $n = 2$: $\frac{1}{16} \le \frac{1}{10} \le \frac14$.

</div>

<Note kind="warn">
להחליף מונה $n+1$ ב-$n$ זה **להקטין** את המונה: זה נותן חסם מלמטה, לא מלמעלה. ולהגדיל מכנה נותן חסם מלמטה. לפני כל החלפה שאלו: האם השבר גדל או קטן?
</Note>

</Explain>

<Example id="ex-0-7-1" title="קטע, ואיחוד של קטעים">

פתרו, וכתבו את קבוצת הפתרונות כקטע או כאיחוד של קטעים:

(א) $|3-2x| < 5$.

(ב) $|x+4| \ge 2$.

<Solution>

**נתון:** שני אי-שוויונות עם ערך מוחלט אחד.

**רעיון:** $|t| < r$ הוא "וגם" ($-r < t < r$) ונותן קטע; $|t| \ge r$ הוא "או" ונותן שני חלקים.

**חישוב (א):** $|3-2x|<5$ שקול ל-$-5 < 3 - 2x < 5$. מחסירים 3: $-8 < -2x < 2$. מחלקים ב-$-2$, שהוא **שלילי**, ולכן שני הסימנים מתהפכים: $4 > x > -1$. הפתרון: $(-1, 4)$.

**חישוב (ב):** $|x+4| \ge 2$ שקול ל-$x + 4 \ge 2$ או $x + 4 \le -2$, כלומר $x \ge -2$ או $x \le -6$. הפתרון: $(-\infty, -6] \cup [-2, \infty)$.

**בדיקה:** ב-(א), לפי $|-u| = |u|$ ו-$|xy| = |x|\cdot|y|$: $|3-2x| = |2x-3| = 2\left|x - 1.5\right|$, ולכן אי-השוויון הוא $|x-1.5| < 2.5$: הקטע שמרכזו $1.5$ ורדיוסו $2.5$, כלומר $(-1, 4)$. ב-(ב), $|x+4|$ הוא המרחק מ-$-4$, והקבוצה היא המספרים שמרחקם מ-$-4$ לפחות 2: עד $-6$ משמאל, ומ-$-2$ מימין, עם הקצוות. בדיקת נקודה: $x = -4$ נותן $0 \ge 2$, שקר, ו-$-4$ אכן לא בקבוצה.

**מסקנה:** (א) $(-1,4)$. (ב) $(-\infty,-6]\cup[-2,\infty)$.

</Solution>

</Example>

<Example id="ex-0-7-2" title="מקטע לערך מוחלט, ובחזרה">

(א) כתבו את הקטע $(-3, 7)$ בצורה $\{x : |x-a| < r\}$, ואת הקטע $[2, 2.5]$ בצורה $\{x : |x-a| \le r\}$.

(ב) נכון או לא נכון: יש $a$ ו-$r>0$ כך ש-$\{x : |x-a| < r\} = (0,1) \cup (1,2)$. נמקו.

<Solution>

**רעיון:** לקטע המרכז הוא האמצע והרדיוס חצי האורך. וקבוצה מהצורה $|x-a|<r$ היא תמיד קטע אחד, בלי "חורים".

**חישוב (א):** ל-$(-3,7)$: המרכז $\frac{-3+7}{2} = 2$ והרדיוס $\frac{7-(-3)}{2} = 5$, ולכן $(-3,7) = \{x : |x-2| < 5\}$. ל-$[2, 2.5]$: המרכז $2.25$ והרדיוס $0.25$, ולכן $[2,2.5] = \{x : |x - 2.25| \le 0.25\}$ (הקצוות שייכים, ולכן $\le$).

**הוכחה (ב):** לא נכון. נניח בשלילה שיש $a$ ו-$r>0$ כאלה. אז $\{x : |x-a|<r\}$ הוא הקטע $(a-r, a+r)$. הנקודות $0.5$ ו-$1.5$ שייכות ל-$(0,1)\cup(1,2)$, ולכן גם לקטע: $a - r < 0.5$ ו-$1.5 < a + r$. אז $a - r < 0.5 < 1 < 1.5 < a + r$, כלומר $1$ שייך לקטע. אבל $1 \notin (0,1)\cup(1,2)$. סתירה.

**בדיקה:** ב-(א), נקודות הקצה: $|-3-2| = 5$ ו-$|7-2| = 5$, בדיוק הרדיוס, ולכן הן מחוץ לקטע הפתוח, כמו שצריך. ב-(ב), הקבוצה $(0,1)\cup(1,2)$ היא $\{x : 0 < |x-1| < 1\}$: הקטע סביב 1 בלי המרכז שלו. כדי לתאר אותה צריך שני תנאים, לא אחד.

**מסקנה:** (א) $|x-2|<5$ ו-$|x-2.25| \le 0.25$. (ב) לא נכון: קבוצה מהצורה $|x-a|<r$ היא קטע, ואין בה חורים.

</Solution>

</Example>

<Example id="ex-0-7-3" title="נכון או לא נכון: שלוש טענות על ערכים מוחלטים">

קבעו לגבי כל טענה אם היא נכונה לכל $a, b$ ממשיים. הוכיחו את הנכונות והביאו דוגמה נגדית לשאינן.

(א) $|a-b| \le |a| + |b|$.

(ב) $|a+b| \ge |a| - |b|$.

(ג) אם $|a| < 1$ ו-$|b| < 1$, אז $|a-b| < 1$.

<Solution>

**רעיון:** טענות (א) ו-(ב) הן אי-שוויון המשולש וצורתו ההפוכה אחרי הצבה מתאימה. ב-(ג) שני מספרים קרובים לאפס יכולים להיות רחוקים זה מזה, אם הם בצדדים מנוגדים.

**הוכחה (א):** נכון. לפי אי-שוויון המשולש עם $a$ ו-$-b$: $|a-b| = |a + (-b)| \le |a| + |-b| = |a| + |b|$.

**הוכחה (ב):** נכון. לפי הצורה ההפוכה עם $a$ ו-$-b$: $|a + b| = |a - (-b)| \ge \big||a| - |-b|\big| = \big||a|-|b|\big| \ge |a| - |b|$. (האי-שוויון האחרון: כל מספר קטן או שווה לערך המוחלט שלו.)

**הוכחה (ג):** לא נכון. דוגמה נגדית: $a = 0.9$, $b = -0.9$. אז $|a| = |b| = 0.9 < 1$, אבל $|a - b| = 1.8 \ge 1$.

**בדיקה:** מה כן נכון ב-(ג)? לפי (א), $|a-b| \le |a|+|b| < 1 + 1 = 2$. והחסם 2 לא ניתן לשיפור, אבל דוגמה אחת לא מראה את זה; צריך משפחה של דוגמאות. לכל $0 < t < 1$ ניקח $a = 1-t$ ו-$b = -(1-t)$: שניהם בקטע $(-1,1)$, ו-$|a-b| = 2 - 2t$. אם $M < 2$, נבחר $t < \frac{2-M}{2}$, ואז $|a-b| = 2 - 2t > M$. לכן אף מספר קטן מ-2 אינו חוסם את $|a-b|$.

**מסקנה:** (א) נכון, (ב) נכון, (ג) לא נכון: שני מספרים בקטע $(-1,1)$ יכולים להיות במרחק כמעט 2 זה מזה.

</Solution>

</Example>

<Example id="ex-0-7-4" title="הפרש של ערכים מוחלטים">

פתרו את אי-השוויון $|x+3| - |x-1| \ge 2$.

<Solution>

**נתון:** הפרש של שני ערכים מוחלטים, שמחליפים סימן ב-$x = -3$ וב-$x = 1$.

**רעיון:** מפצלים את הישר לשלושה חלקים לפי $-3$ ו-$1$, ובכל חלק כותבים את הביטוי בלי ערך מוחלט.

**חישוב:**
- $x \ge 1$: שני הביטויים אי-שליליים, וההפרש הוא $(x+3) - (x-1) = 4$. $4 \ge 2$ תמיד: כל החלק פותר, $[1, \infty)$.
- $-3 \le x < 1$: $|x+3| = x+3$ ו-$|x-1| = 1-x$, וההפרש הוא $2x + 2$. התנאי $2x + 2 \ge 2$ נותן $x \ge 0$. בחלק הזה: $[0, 1)$.
- $x < -3$: $|x+3| = -x-3$ ו-$|x-1| = 1-x$, וההפרש הוא $-4$. $-4 \ge 2$ אף פעם.

הפתרון: $[0,1) \cup [1,\infty) = [0, \infty)$.

**בדיקה:** לפי הצורה ההפוכה של אי-שוויון המשולש, $|x+3| - |x-1| \le \big|(x+3) - (x-1)\big| = 4$ לכל $x$, ואכן בחלק הימני ההפרש הוא בדיוק 4. בדיקת נקודות: $x = 0$ נותן $3 - 1 = 2 \ge 2$ (קצה שייך); $x = -0.5$ נותן $2.5 - 1.5 = 1 < 2$ (לא שייך).

**מסקנה:** $[0, \infty)$.

</Solution>

</Example>

<Example id="ex-0-7-5" title="מספר קרוב ל-2 רחוק מאפס">

(א) הוכיחו: אם $|x-2| < 1$, אז $\left|\frac1x - \frac12\right| \le \frac{|x-2|}{2}$.

(ב) מצאו $r > 0$ כך שלכל $x$ עם $|x-2| < r$ מתקיים $\left|\frac1x - \frac12\right| < 0.01$.

<Solution>

**נתון:** $|x-2|<1$.

**צריך להוכיח (א):** $\left|\frac1x - \frac12\right| \le \frac{|x-2|}{2}$.

**רעיון:** מכנה משותף: $\frac1x - \frac12 = \frac{2-x}{2x}$. המונה הוא בדיוק המרחק שנתון. את המכנה צריך לחסום **מלמטה**, כדי שהשבר יהיה חסום מלמעלה, ולשם כך הצורה ההפוכה של אי-שוויון המשולש.

**הוכחה (א):**
1. לפי הצורה ההפוכה, $|x| = |2 + (x-2)| \ge |2| - |x-2| > 2 - 1 = 1$. בפרט $x \ne 0$, ו-$\frac{1}{|x|} < 1$.
2. $\left|\frac1x - \frac12\right| = \left|\frac{2-x}{2x}\right| = \frac{|x-2|}{2} \cdot \frac{1}{|x|}$.
3. $\frac{|x-2|}{2} \ge 0$ ו-$\frac{1}{|x|} < 1$, ולכן המכפלה קטנה או שווה ל-$\frac{|x-2|}{2}$.

**חישוב (ב):** זה מהלך חדש: את $r$ עוד לא יודעים, ולכן רושמים קודם מה הוא צריך לקיים, ורק בסוף בוחרים $r$ שמקיים הכול. יש שתי דרישות.
1. $r \le 1$: אז כל $x$ עם $|x-2| < r$ מקיים גם $|x-2| < 1$, ולכן (א) חל עליו.
2. החסם של (א) קטן מ-$0.01$: אם $|x-2| < r$, אז $\left|\frac1x - \frac12\right| \le \frac{|x-2|}{2} < \frac{r}{2}$, ולכן **מספיק** ש-$\frac r2 \le 0.01$, כלומר $r \le 0.02$.

$r = 0.02$ מקיים את שתי הדרישות, ולכן הוא מתאים.

**בדיקה:** עבור $x = 2.0199$ (קרוב לקצה): $\left|\frac{1}{2.0199} - \frac12\right| \approx 0.0049 < 0.01$, והחסם של (א) נותן $\frac{0.0199}{2} = 0.00995$. איפה השתמשנו בהנחה $|x-2|<1$? רק כדי לקבל $|x| > 1$. בלעדיה $x$ יכול להיות קרוב לאפס, ואז $\frac1x$ ענק.

**מסקנה:** (א) הוכח. (ב) $r = 0.02$ מתאים (וכל $r$ חיובי קטן ממנו).

</Solution>

</Example>

<Example id="ex-0-7-6" title="חסם מלמעלה ומלמטה לאותו שבר">

(א) הוכיחו שלכל $x > 0$ מתקיים $0 < \frac{x}{x^2+1} \le \frac12$, ומצאו מתי יש שוויון בחסם העליון.

(ב) הוכיחו שלכל $n$ טבעי $\frac{1}{2n} \le \frac{n}{n^2+1} \le \frac1n$.

<Solution>

**רעיון:** ב-(א) אי-שוויון הממוצעים על $x^2$ ועל $1$ נותן $x^2 + 1 \ge 2x$: חסם מלמטה על המכנה, ולכן חסם מלמעלה על השבר. ב-(ב) מעריכים את המכנה בעזרת החזקה הגבוהה ביותר בו, $n^2$, ו-$1 \le n^2$.

**הוכחה (א):** המונה והמכנה חיוביים, ולכן $\frac{x}{x^2+1} > 0$. לפי אי-שוויון הממוצעים עם $a = x^2 \ge 0$ ו-$b = 1$: $\frac{x^2+1}{2} \ge \sqrt{x^2} = |x| = x$, כלומר $x^2 + 1 \ge 2x > 0$. מחלקים את שני האגפים ב-$2(x^2+1)$, שהוא חיובי: $\frac{x}{x^2+1} \le \frac12$. שוויון יש בדיוק כש-$x^2 = 1$, ועם $x>0$ זה $x = 1$.

**הוכחה (ב):** מלמעלה: $n^2 + 1 > n^2$, ולכן $\frac{n}{n^2+1} < \frac{n}{n^2} = \frac1n$. מלמטה: לכל $n \ge 1$, $1 \le n^2$, ולכן $n^2 + 1 \le 2n^2$, ו-$\frac{n}{n^2+1} \ge \frac{n}{2n^2} = \frac{1}{2n}$.

**בדיקה:** $n = 1$: $\frac12 \le \frac12 \le 1$, והחסם התחתון מתקבל. $n = 3$: $\frac16 \le \frac{3}{10} \le \frac13$. ב-(א), $x = 1$ נותן $\frac{1}{2}$ בדיוק, ו-$x = 2$ נותן $\frac25 < \frac12$.

**מסקנה:** (א) $0 < \frac{x}{x^2+1} \le \frac12$, ושוויון רק ב-$x = 1$. (ב) $\frac{1}{2n} \le \frac{n}{n^2+1} \le \frac1n$: שני חסמים מאותו סוג, $\frac{c}{n}$. בפרק 2 חסם כזה מלמעלה הוא בדיוק מה שמוכיח שסדרה שואפת לאפס.

</Solution>

</Example>

<Summary title="מה למדנו">

- $|x| = x$ כש-$x \ge 0$ ו-$|x| = -x$ כש-$x < 0$. $|x-a|$ הוא המרחק בין $x$ ל-$a$.
- עבור $r > 0$: $|t| < r \iff -r < t < r$ ("וגם": קטע אחד), ו-$|t| > r \iff t > r$ או $t < -r$ ("או": איחוד של שני חלקים). עם $\le$ ו-$\ge$ הקצוות שייכים.
- $|x-a| < r$ הוא הקטע הפתוח $(a-r, a+r)$, שמרכזו $a$ ורדיוסו $r$. בפרק 2: $|x-L|<\varepsilon$ פירושו $L-\varepsilon < x < L+\varepsilon$.
- כמה ערכים מוחלטים: מפצלים לפי הנקודות שבהן כל ביטוי מחליף סימן, פותרים בכל חלק, ומאחדים.
- **אי-שוויון המשולש:** $|a+b| \le |a|+|b|$, בשוויון בדיוק כש-$ab \ge 0$. **הצורה ההפוכה:** $\big||a|-|b|\big| \le |a-b|$. הראשון חוסם מלמעלה, השני מלמטה.
- **אי-שוויון הממוצעים:** לכל $a, b \ge 0$, $\frac{a+b}{2} \ge \sqrt{ab}$, בשוויון רק כש-$a = b$. הוא דורש $a, b \ge 0$.
- חסם מלמעלה לשבר חיובי: מגדילים מונה או מקטינים מכנה; חסם מלמטה: להפך. כל החלפה מנומקת לכל ערך בתחום.
