# אינפי 1 — ספר לימוד חי

קורס אינטראקטיבי בעברית ללימוד עצמי של חשבון אינפיניטסימלי במשתנה אחד, ברמה אוניברסיטאית, לפי הסילבוס של
הקורס **80131 "חשבון אינפיניטסימלי (1)"** באוניברסיטה העברית: המספרים הממשיים, סדרות וגבולות, פונקציות ממשיות
וגבולותיהן, רציפות ונגזרות. לפניו פרק 0 על השפה של ההוכחה, ואחריו פרק גשר לאינפי 2.

לכל פרק יש מסלול מדורג: **שאלות הבנה** לכל שיעור (בסיס, בינוני, מבחן), **שאלות חזרה** על כל הפרק, **שאלות מבחן**
עם הוכחה מלאה, מחוון להערכה עצמית, ו**מבחן פרק** מוגרל עם דוח.

הקורס בנוי על הפלטפורמה של קורסי האחות "חשמל ומגנטיות" (emlab) ו"אופטיקה" (optlab): Astro 7, Preact, MDX ו-KaTeX,
בעיצוב של "ספר חי".

**מצב:** הפלטפורמה מוכנה ובנקי השאלות של כל הפרקים כתובים (שלב 0). השיעורים עצמם עוד לא נכתבו; דף התרגול של כל פרק
הוא נקודת הכניסה. האתר לא פורסם.

```powershell
npm install
npm run dev            # http://localhost:4321
npx vitest run         # math + unit tests
npm run lint:content   # schemas, TeX, objectives, question-bank completeness
npm run build          # static site -> dist/
npm run e2e            # Playwright against the preview server on :4341
```
